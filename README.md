# grounded

november 13 2026. the faa stops every departure in america. this is a shared looping replay of that afternoon, the sky emptying out and filling back up. every airport is a candle that burns with its traffic

## what you can do

- watch the whole day play back, the stop and the restart
- watch it together with everyone else on the page at the same time
- flip to the live sky, whats flying right now
- every airport glows brighter the more traffic it has

## run it

`npm i` then `vercel dev`. flight data lives in the json and bin.gz files at the root
